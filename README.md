# Masutha Farming Website
Static responsive website for Masutha Farming, built for GitHub Pages.

## Publish with GitHub Pages
1. Upload all files and folders to the root of a GitHub repository.
2. Open repository Settings > Pages.
3. Under Build and deployment choose **Deploy from a branch**.
4. Select **main** and **/(root)**, then Save.

The site uses only HTML, CSS and JavaScript and requires no server-side runtime.
